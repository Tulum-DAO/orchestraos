# Provider marks

Official marks only, downloaded on 2026-10-27 from each provider's own brand or press materials. These
files are **trademarks of their owners. They are not covered by this project's MIT licence.** They are
used only to identify which provider runs an agent seat (nominative use) and must be used as the owners
provide them: no recolouring, redrawing, stretching or effects. The avatar badge draws each file
unmodified, at full badge size with no plate, and picks the owner's own light or dark variant.

| file used by the badge | provider | source | notes |
|---|---|---|---|
| `claude-spark-clay.svg` | Anthropic, Claude | Anthropic's press kit, "Claude Spark - Clay" SVG | Byte-identical. The kit ships only the Clay spark, so light and dark both use it. |
| `openai-blossom-black.svg`, `openai-blossom-white.svg` | OpenAI | The Blossom path from OpenAI's official site icon | OpenAI's brand page has no downloadable Blossom file. The path is taken unchanged, in the two colours the official icon itself uses: black for light, white for dark. Brand rules: don't add colours to the Blossom, and don't use it as primary branding. |
| `gemini-sparkle.svg` | Google, Gemini | Google's published Gemini sparkle SVG | Byte-identical classic gradient sparkle. |
| `grok-mark-dark.svg`, `grok-mark-light.svg` | xAI, Grok | xAI's brand assets, Grok logomark (dark mark for light backgrounds, light mark for dark backgrounds) | Byte-identical. |
